    3. SOHO Network Architecture (Networking)

    Focus: Cisco Packet Tracer, Subnetting, Security
    Status: Completed

    Designed a complete Small Office/Home Office (SOHO) network simulation. I configured routers and switches to segment traffic using VLANs, creating a secure boundary between "Employee" and "Guest" traffic. I also implemented basic ACLs (Access Control Lists) to prevent unauthorized access to the server subnet. This project helped me visualize the flow of packets and the importance of the OSI model in troubleshooting.

    5. "Zodiac Logic" Engine (Java)

    Focus: Complex Logic Chains, Input Sanitization, Data Parsing
    Status: Completed

    This Java application takes a raw date input (e.g., "10/31") and parses it into integers to determine astrological signs. The challenge here was data validation.

    Instead of simple text matching, I engineered a mathematical solution where dates are converted to a single integer value (e.g., October 31 becomes 1031). This allowed me to use efficient numerical comparison operators rather than messy string logic. I also implemented a robust validation loop that refuses to crash even if the user types gibberish.

    6. The Emoji Translator (Python)

    Focus: Algorithms, Data Structures (Lists), String Manipulation
    Status: Completed

    A text-processing algorithm that maps English words to their emoji counterparts. This project relies on Parallel Arrays—searching through a list of keywords and pulling the data from the exact same index in a corresponding "Emoji List."

    It features a CLI (Command Line Interface) menu system that allows the user to encode (Text -> Emoji) or decode (Emoji -> Text) continuously until they choose to exit.

    7. Academic Progress Tracker (Java)

    Focus: Data Parsing, Arithmetic Logic, Ternary Operators
    Status: Completed

    A CLI tool designed to help students track their academic timeline. The program accepts user input for program length and current status, then calculates the remaining workload.

    • Data Parsing: Handles string-to-integer conversion (`Integer.parseInt`) to perform mathematical operations on user text input.

    8. "Storm Tracker" Physics Engine (Java)

    Focus: Scientific Calculation, Input Validation, Exception Handling
    Status: Completed

    This application solves a classic physics problem: calculating the distance of a lightning strike based on the speed of sound. It converts the time delay (in seconds) into both Kilometers and Miles using precise floating-point constants.

    The Challenge:

    The main focus of this project was Robust Input Validation. I built a `do-while` loop combined with `try-catch` blocks to "trap" the user until they provide valid data. If a user enters letters or negative numbers, the program catches the error, displays a helpful message, and re-prompts them without crashing.
